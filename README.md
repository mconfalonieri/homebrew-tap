# Homebrew tap for mconfalonieri's projects

This repository containds the formulae for installing my programs on MacOS
using Homebrew.

To take advantage of this system, please make sure to have Homebrew installed,
then:

```bash
brew tap mconfalonieri/tap
```
and you are ready to go!

Currently, the following programs are available:

| Name    | Formula   | Description                          |
| ------- | --------- | ------------------------------------ |
| Sadplay | `sadplay` | SDL nostalgic player for AdLib files |
| Gomines | `gomines` | terminal minesweeper game            |

Use the **formula** name to install using Homebrew.

For example, to install Gomines:

```bash
brew install gomines
```
